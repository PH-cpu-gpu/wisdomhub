## Platform

web

## Users

**首要用户：技术面试官与技术评审。** 他们在招聘或作品评审场景下打开站点，时间有限，要判断项目是否真的跑通了完整链路、技术深度是否可信。

**产品用户：程序员、开发者与计算机相关学习者。** 他们在技术学习与交流场景中使用站点：读文章、查问答、按技术体系探索、向 AI 导师提问。这层用户定义了页面该有的真实功能，但当前前端取舍的第一优先级仍是「让评审者看懂并信任这套系统」。

## Product Purpose

WisdomHub 是面向开发者的技术知识社区平台：技术文章发布与阅读、技术问答、评论/点赞/收藏/关注、全文搜索、技术知识图谱、个性化推荐、付费专栏、AI 技术导师与文章知识抽取。

项目当前首先是一份求职作品。成功不是用户增长，而是能在可运行的站点里完整演示一条闭环：**内容 → 用户行为 → 知识图谱 → 推荐 → AI 导师**，并让评审者相信每一环都是真实实现。

## Positioning

**图谱 + AI 导师闭环。** 知识图谱提供技术之间的结构化关系与前置链，AI 导师以图谱为上下文做问答、学习规划与文章分析。普通博客站或单点 AI Chat 都无法如实复制这一组合。

## Operating Context

- 简体中文站点；浏览器使用，桌面为主，同时需要覆盖窄屏。
- 公开访客可浏览文章、问答、标签与技术详情；写作、提问、点赞、收藏、关注、通知与个人中心需要登录。
- 登录只接受手机号或邮箱；注册时只提供其中一个，登录后补绑邮箱；用户名是显示名，不是登录标识。手机号绑定当前不开放（无短信通道）。
- 写作流程是 Markdown 编辑器 + 实时预览 + 草稿自动保存 + 发布。
- 系统没有管理员、后台、审核或版主角色，只有「属主」一种权限维度：用户只能修改自己的内容。
- 付费专栏走模拟支付流程，不接真实支付渠道。
- 评审通常通过本地运行观察：Docker 中间件、Nacos、网关与各微服务启动后，前端经 `/api` 反向代理访问网关。

## Capabilities and Constraints

**已实现的核心内容表面：** 首页文章列表、文章详情与评论、Markdown 编辑器与草稿、标签列表/详情、问答列表/提问/详情、用户主页、个人中心（资料、我的文章、草稿箱、我的收藏）、登录/注册。

**仍为占位页：** 搜索、知识图谱、技术详情、通知中心、专栏列表/详情、AI 技术导师。

**前端技术约束：**

- Vue 3 + Vite + TypeScript + Vue Router 4 + Pinia + Element Plus（按需引入）。
- 自托管 IBM Plex Sans / IBM Plex Mono（latin 子集）；中文使用系统字体栈。
- 主键 ID 在 JSON 中序列化为字符串（雪花 ID 超出 JS 安全整数）；计数类字段保持数字。
- 时间统一为带 `Z` 的 UTC ISO-8601 字符串。
- HTTP 契约：网关返回的 HTTP 状态码恒为 200，成败与类别由响应体 `code` 表达，前端以 `code === 200` 判定成功。网关自身产生的 4xx（如 `/internal/**` 的 403、限流 429）可能不是统一 `{code,message,data}` 结构，请求层保留兜底分支。
- SSE 与文件下载不走统一响应包装。

**未定 / 待确认：** 真实内容规模、上线部署方式、真实用户指标。

## Brand Commitments

- 产品名：**WisdomHub**；浏览器标题与应用名一致，界面语言为简体中文。
- 用户已确认的品牌视觉方向：**开发者终端风、暗色优先**。这是约束，不在本文件中展开为配色或组件规范。

## Evidence on Hand

- **没有**文章正文、真实用户、评论、客户、案例、评价、媒体曝光、性能指标或商业数据入库；未来的界面不得编造这些内容。

## Product Principles

1. **闭环必须可演示。** 每个表面优先连接到真实链路与真实数据；宁可呈现完整空状态，也不伪造文章、用户、评论或指标。
2. **图谱与 AI 是识别性核心。** 内容、标签与问答的组织方式要服务于「技术关系 + AI 导师」这条主线，不做成又一个普通博客。
3. **技术深度要能被看见。** 搜索、推荐、实时通知、图谱与 AI 这些能力应在交互中可感知，而不是只存在于技术文档和简历里。
4. **中文开发者语境。** 界面、文案与空状态用中文写作，公认英文技术名词保留原文，不为了「国际化观感」牺牲可读性。
5. **属主优先。** 只有内容作者能修改自己的内容；不设计管理员、审核或角色管理入口。
